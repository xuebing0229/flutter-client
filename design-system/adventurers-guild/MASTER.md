# 冒险者公会 UI 风格系统

> 这是 UI 风格实现的单一真源。
> 视觉依据优先级：用户提供的《14 种经典的 UI/UX 设计风格》DOCX 内嵌 HTML/CSS > 当前 App 已确认布局 > 通用 UI/UX 规则。
> 不要自行把风格改成“更高级”“更克制”或其它审美方向。

## 设置结构

外观设置分成两个独立维度：

- **UI主题色**：决定主强调色。
- **UI风格**：决定形状、阴影、边框、材质、背景关系和组件语言。

切换 UI 风格不能修改或覆盖用户保存的主题色；渲染时将两者组合。

UI 风格与明暗模式也必须独立：除“复古浅色 / 复古深色”本身明确指定明暗外，其余风格必须跟随 App 当前的浅色、深色或跟随系统设置。玻璃在浅色模式必须使用乳白/浅灰蓝的清透基底，不能因为选择“玻璃”而自动进入黑色界面。

## 主题色组合规则

主题色始终保留为 `ColorScheme.primary`。

- 浮雕、极简、粗边、黑白、黏土、玻璃：主题色直接用于主按钮、选中态、进度和重点边框。
- 几何：主题色作为主几何色，其它色由主题色旋转色相派生，不固定死用红黄蓝。
- 复古浅色、复古深色：主题色作为主强调色，再派生邻近/对比色形成复古多色关系。
- 荧光：主题色作为主荧光色，第二荧光色由主题色派生。
- 拼贴：主题色是最主要撞色，其它撞色由主题色派生。

## 组件覆盖范围

每个风格必须同时作用于共享组件，而不是只改背景：

- 页面背景
- AppBar / 底部导航 / 抽屉 / Windows 侧栏
- 排单卡片 / 成品卡片 / 设置卡片
- 按钮
- 输入框
- 开关 / 复选框 / 单选
- 标签 / Chip
- 进度条
- 弹窗 / 菜单 / BottomSheet
- FAB
- 选中态和边框

## 关键视觉参数

### 浮雕

参考文档：背景与卡片同色；双向浅/深阴影；圆角 12–18；输入区域偏内凹；无明显边框。

### 极简

参考文档：低装饰；0 圆角或极小圆角；细分隔线；无阴影。示范里的局部竖线不能机械复制到排单/成品等业务卡片中；业务卡片优先用留白和分隔线建立层级。

### 粗边

参考文档：3–4px 硬边框；0 圆角；硬偏移阴影；高对比；主题色作为主色块。

### 几何

参考文档：3px 左右硬边；0 圆角；几何色块；轻硬阴影；主题色及其派生色共同使用。

### 复古浅色

参考文档：暖浅背景；2px 边框；4–8px 圆角；主题色与派生色形成复古多色；轻硬偏移阴影。

### 复古深色

参考文档：深色底；细霓虹边；主题色与派生色发光；圆角 4–8；允许 glow。

### 荧光

参考文档：接近黑色背景；1–2px 荧光边；高饱和主题色；明显 glow；圆角接近 0。

### 拼贴

参考文档：不规则圆角；较粗边；多色硬阴影和撞色；主题色为主撞色。

### 黑白

参考文档：灰阶背景；2px 直线边框；0 圆角；无柔和阴影；主题色只用于必要强调。

### 黏土

参考文档：20px 左右厚圆角；厚实偏移阴影；柔和表面；主题色作为主色块并派生多色。

### 玻璃

参考文档中的“水滴边框效果”：真实背景上使用 24–30px 级局部模糊、多层径向渐变、顶部与左侧更亮而底部/右侧更暗的双色边、内侧高光线、水滴表面椭圆高光与轻微暗边。主题色只进入局部折色/强调，不把玻璃本体染成实色。

## 不允许

- 不要只给卡片换一个透明度就称为新风格。
- 不要把 12 个风格做成同一个圆角模板只换颜色。
- 不要用英文风格名出现在设置页。
- 不要因为风格切换改变排单业务布局、功能入口、字段或数据。
- 不要覆盖用户选中的 UI 主题色。


## 148 视觉偏差复盘

148 只把文档风格压缩成通用 ThemeData / BoxDecoration token，导致质感不足。后续实现必须遵守：

- 浮雕：外凸和内凹必须分开渲染；输入/轨道必须有 inset 明暗边。
- 粗边：硬边与硬偏移阴影是两层独立结构，不能用普通 Material elevation 替代。
- 复古深色：必须包含 CRT 扫描线、60px 级网格与暗角。
- 荧光：必须包含点阵背景、内外 glow 和局部高亮线。
- 拼贴：以 Anti-Design Lite 为准，保留轻微旋转、彩色偏移阴影和不规则几何细节，不使用早期极端 Anti-Design 文件。
- 黏土：必须使用厚圆角、无模糊偏移阴影和内凹轨道。
- 玻璃：以 Liquid Glass 水滴边框 HTML 为准，必须有非对称亮边、多层径向高光、真实 BackdropFilter 与内侧高光弧线。


## 149 实机反馈修正规则

- 搜索栏等“外层已经使用 GuildStyledSurface 的组件”不得再在内部绘制第二套硬边框/实色 Material 外壳。
- 账号页、专注页、设备同步页、前台同步浮窗等共享卡片必须使用统一的风格 Surface，避免换风格后出现固定 18px 白色硬矩形。
- 排单、成品等业务卡片不使用无语义的左侧装饰竖线；风格差异通过边框、阴影、局部几何标记和材质表达。
