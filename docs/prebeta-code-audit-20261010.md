## 保留而非清理的关键安全能力

- 同步操作 ID、向量时钟、字段级冲突和删改冲突提示。
- 离线设备确认、操作历史压缩标记、删除标记的安全期。
- 账号绑定检查、备份导入身份校验、原子文件写入。
- 更新包 SHA-256 完整性校验、激活码签名校验。
- 跨设备不同字段自动合并、销售和补减款操作合并、参考图资产同步。

上述机制若发生变更，应先展示等价性证明和回归用例，不能以“过度防御”为由直接移除。

## 进入内测前仍需补齐的验证

1. 双端离线同时修改、删除与编辑冲突、二次同步、设备解绑、历史 GC（真实 Android + Windows）。
2. 大体积参考图多端同步、完整备份、恢复、进度、空间不足及回滚。
3. 成品多次售卖价格变化后的历史收入归属与退款/减款边界；米画师取整、画加阶梯、不同平台默认手续费。
4. 本地写入失败、应用后台切换、强杀进程、账户切换时的状态持久化。
5. Android 无法精确闹钟、通知权限拒绝、杀进程及重启后的截稿提醒。
6. 更新暂停/继续、服务器不支持 Range、错误哈希、旧版残留、Windows 安装器回滚、桌宠宿主退出。
7. OCR 真实截图矩阵：米画师/画加详情及列表、价格、重复识别、跨平台、批量编辑保存。
8. 桌宠各预设独立位置、横竖气泡字号一致、极大字号不崩溃、计时器与气泡互不遮挡。
