# One-time activation

冒险者公会的账号本体仍然是本地优先设计，但“创建一个全新的账号”现在需要一次联网核销。

## 边界

- 激活码只在首次注册时使用。
- 同一枚激活码只能成功创建一个账号。
- 激活服务器只保存激活码账本、生成者、售出人、核销时间等授权信息。
- 账号名、密码、头像、排单、成品、图片和设备同步数据都不会发送到激活服务器。
- 注册成功后，普通登录、离线使用、备份和 P2P 设备同步都不访问激活服务器。
- 新设备加入已有账号仍走现有的设备配对/备份流程，不再次消耗激活码。
- 如果未来停止运营激活服务器，已有账号继续正常工作，只是不再允许创建新账号。

## 一码一账号

买家 App 会先在本地验证 Ed25519 签名，再向服务器提交激活码和一个随机 claimId。

服务器在 SQLite 写事务中原子核销：

- 未核销：记录 redeemed_at 和 claimId，注册通过。
- 已由同一 claimId 核销：视为同一次注册的安全重试。
- 已由其他 claimId 核销：拒绝，返回 already_redeemed。

App 会在联网前持久化 claimId。即使服务器已经核销后网络断开或 App 崩溃，下一次输入同一码也会复用原 claimId，不会把用户自己误判成重复注册。

## 发码器

发码器不再自己决定全局编号。联网流程为：

1. 服务器原子预留 serial 和 accountId。
2. 发码器在本机使用 Ed25519 私钥签名，私钥不会上传服务器。
3. 发码器把完整 AW1 激活码提交回服务器登记。
4. 多个管理者看到同一份服务器账本，并分别记录谁生成、谁售出。

旧离线发码记录在首次连接服务器时会尝试迁移到服务器账本。

## 密钥

- Ed25519 私钥只保存在发码器设备安全存储中。
- 冒险者公会 App 和激活服务器只持有公钥。
- 服务器数据库和管理员凭据可迁移到其他机器，因此授权服务不绑定某一家云厂商。
